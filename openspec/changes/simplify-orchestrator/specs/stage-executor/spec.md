# stage-executor (delta)

## ADDED Requirements

### Requirement: Исполнение этапа только через интерфейс Executor
Все способы исполнения этапа SHALL реализовывать единый интерфейс
`engine.Executor` с сигнатурой `Run(ctx, StageContext) (Result, error)`:
внутренний агент, именованный внешний адаптер и Docker. Движок MUST NOT
выбирать конкретную реализацию через switch по типу исполнителя; выбор MUST
осуществляться регистрацией реализации под именем.

#### Scenario: Добавление нового исполнителя без правки движка
- **WHEN** разработчик регистрирует новую реализацию `Executor` под именем
- **THEN** этап может ссылаться на неё из конфигурации, и код `pkg/engine/`
  остаётся неизменным

#### Scenario: Единый результат для всех исполнителей
- **WHEN** этап исполняется любым зарегистрированным исполнителем
- **THEN** результат представлен единым типом `Result`, а не
  специфичными для исполнителя структурами
