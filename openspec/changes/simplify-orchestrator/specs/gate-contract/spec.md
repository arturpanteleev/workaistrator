# gate-contract (delta)

## ADDED Requirements

### Requirement: Единый интерфейс Gate
Все гейты SHALL реализовывать единый интерфейс `engine.GateRunner` с сигнатурой
`Check(ctx, Gate, StageContext) (Decision, error)`. Регистрация нового типа
гейта MUST сводиться к реализации интерфейса и одной записи в реестре, без
изменения кода планировщика гейтов.

#### Scenario: Регистрация нового гейта
- **WHEN** разработчик реализует `GateRunner` и регистрирует его в реестре
- **THEN** гейт доступен этапам без правок планировщика и машины состояний

### Requirement: Каталог встроенных типов гейтов
Движок SHALL предоставлять четыре встроенных типа гейтов: `program`
(внешняя программа или Docker), `llm`, `human` и `required_phrases`.
Прочие проверки MUST выражаться конфигурацией типа `program`.

#### Scenario: Прочие проверки через program
- **WHEN** требуется проверка, не покрытая типами `llm`, `human`,
  `required_phrases`
- **THEN** она описывается как гейт типа `program` с соответствующей командой,
  без введения нового встроенного типа
